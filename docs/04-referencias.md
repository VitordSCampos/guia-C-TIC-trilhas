# 4. Referências

- **Curso em Vídeo — C** (Gustavo Guanabara): curso em vídeo gratuito, em português, muito usado como primeiro contato com a linguagem.
- **beecrowd** (antigo URI Online Judge): banco de exercícios de programação com correção automática, ótimo para praticar C do básico ao avançado.
- **cppreference.com**: referência técnica completa da linguagem C (e C++), útil para consultar a sintaxe e o comportamento exato de funções da biblioteca padrão.
- **The C Programming Language** (Kernighan & Ritchie): livro clássico escrito pelos próprios criadores da linguagem — referência histórica e ainda muito usada.
- **onlinegdb.com / replit.com**: compiladores online, úteis para praticar sem precisar instalar nada localmente.
