# Guia de Aprendizado — Introdução à Linguagem C


## Sobre este guia

Este é um guia introdutório à linguagem C, pensado para quem está começando do zero — seja para uma disciplina de programação, seja para se preparar para processos seletivos técnicos que cobram lógica de programação e C.

## Público-alvo

Estudantes de Ciência da Computação ou áreas afins que:

- nunca programaram em C antes, mas já têm alguma noção de lógica de programação (variáveis, condicionais, laços em outra linguagem);
- querem uma referência rápida e prática, com exemplos, antes de uma prova ou projeto.

## Objetivos de aprendizagem

Ao final deste guia, você deve ser capaz de:

- explicar os fundamentos da linguagem C e por que ela se mantém relevante até os dias atuais;
- escrever, compilar e executar um programa simples em C;
- declarar variáveis dos tipos primitivos e usar operadores básicos;
- ler e escrever dados com `scanf` e `printf`;
- estruturar decisões com `if`, `else` e `switch`;
- repetir ações com `for`, `while` e `do-while`.

## Como usar

Leia `docs/01-introducao.md` e `docs/02-conceitos.md` nessa ordem, tente os exercícios em `docs/03-exercicios.md` e depois confira o programa completo em `exemplos/exemplo-basico.md`, que junta tudo num único exercício resolvido.

## Pré-requisitos

Nenhum compilador local é necessário para começar — você pode usar o [onlinegdb.com](https://www.onlinegdb.com/) ou o [replit.com](https://replit.com/) direto no navegador.
